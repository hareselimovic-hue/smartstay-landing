Self check-in for apartments: how to welcome guests without being there

The guest arrives at midnight and you're on the other side of town. Self check-in solves that problem, but only if the lock and the instructions are set up well. Here's how.

SmartStay team · Published 6 November 2026 · 7 min read

In short
  • Self check-in means guests let themselves into the apartment, without you meeting them, using a code or a key from a box.
  • The cheapest way to start is a key box with a code; the most convenient in the long run is a smart or electronic lock.
  • Change the code after every guest and send it only 1–2 days before arrival.
  • Instructions with photos are essential. Below is a ready-made template in Bosnian and English.

Why self check-in

A classic welcome means waiting: the flight is late, the guest is stuck in traffic, and your evening is gone. With several apartments it becomes a job in itself. Self check-in brings:

  • Flexibility for guests. They can arrive at any time, without arranging or waiting.
  • Free time for you. You don't have to be physically present at every arrival.
  • A better position on the platforms. On Airbnb and Booking.com you can highlight self check-in, and many guests filter by exactly that.

The downside is less personal contact. That's why good instructions and quick replies to messages matter even more than with a classic welcome.

Options: key box with a code, electronic or smart lock

OptionProsConsBest for
Key box with a code Cheapest, simple to mount, no lock change Guests may forget to return the key; you change the code by hand Getting started, one apartment
Electronic lock with a keypad No key to lose; the code is easy to change Pricier, needs installation and batteries Year-round rentals, several guests a month
Smart lock (app) Remote codes, time-limited access, entry log Most expensive, depends on internet and battery Several apartments, remote management
Key with a trusted person No equipment; the guest still gets human contact Depends on that person's availability A temporary solution

Before installing a lock or key box at the building entrance, check the building rules and agree it with the manager or the neighbours. A box in a shared area without agreement quickly becomes a problem.

Safety: rules that pay off

  • A new code for every guest. Change it after the guest leaves; on a smart lock set a code valid only for the dates of the stay.
  • Send the code late. 1–2 days before arrival, never in the listing or a public message.
  • A spare key. Batteries die, boxes jam. Make sure someone nearby has a spare key.
  • Don't put the address and the code in the same public post, e.g. in a review or on social media.
  • Guest registration. With self check-in, guests still have to be registered as the regulations require. Collect the details in advance, e.g. with an online form before arrival.

Frequently asked questions

Do guests like self check-in?

Most do, especially those travelling late or who don't want to wait. But guests still expect to reach you if something goes wrong. Self check-in without quick replies to messages quickly ends in a bad review.

What if the guest can't open the box or the lock?

That's why a spare key with someone nearby and a phone that is answered in the evening matter. The most common cause is a mistyped code or the wrong door, and photos in the instructions prevent both.

How often should I change the code?

Ideally after every guest. With a key box it takes a minute; with a smart lock the code can expire automatically when the booking ends.

How are guests registered with self check-in?

The obligation to register guests applies whether or not you meet them in person. Collect the ID or passport details before arrival, e.g. with an online form, and register them as usual.
