Automated messages on Airbnb and Booking.com: how to set them up

The messages you send to every guest can be written once and scheduled. Airbnb and Booking.com then send them for you, at the right time, even while you sleep. Here is how to set them up, plus five ready-made messages to copy.

SmartStay team · Published 22 November 2026 · 8 min read

In short
  • Both Airbnb and Booking.com have free scheduled messages: you write a template, choose when it goes out, and the platform sends it to every guest.
  • Five messages are enough: booking confirmation, instructions before arrival, a reminder on arrival day, check-out and a thank-you.
  • The most important one is the message two days before arrival: put the link to all your instructions in it.
  • Below are the steps for both platforms and ready-made messages in Bosnian and English.

Which messages and when

Most guest questions are the same for every booking: when is check-in, how do I get in, where do I park, what is the WiFi password, when is check-out. Send the answers before the guest asks and the questions disappear. The schedule that works best:

  1. Right after bookingA thank-you and confirmation. Ask for an approximate arrival time.
  2. Two days before arrivalAll arrival instructions, ideally as one link.
  3. On arrival day, in the morningA short reminder with the same link.
  4. The day before departureCheck-out time and what to do before leaving.
  5. The day after departureA thank-you and a review request.

How to set up automated messages on Airbnb

On Airbnb these are called scheduled messages. Each scheduled message is a saved template (a quick reply) with a send time added to it.

  1. Open MessagesIn the app or on the web, open Messages, then the messaging settings.
  2. Scheduled messagesChoose Scheduled messages and create a new one. You can also start from an existing quick reply.
  3. Write the messageGive it a name and paste the text. Instead of [guest name], insert the field for the guest's name, date or check-in time using the insert option (shortcodes), so it fills in automatically.
  4. Choose when it is sentThe trigger is a confirmed booking, check-in or check-out. Then choose how many days before or after, and at what time.
  5. Choose listingsSelect which of your listings the message applies to.
  6. Last-minute bookingsTurn on sending for short stays and last-minute bookings too. Otherwise Airbnb skips the message when its send time has already passed, for example when a guest books today for tomorrow.

Airbnb changes its menus from time to time. If you don't see exactly these names, look for Scheduled messages in your messaging settings or in the Airbnb Help Centre.

How to set up automated messages on Booking.com

On Booking.com, messages are set up in the Extranet or in the Pulse app. Only accounts with admin rights can add templates.

  1. Messaging preferencesIn the Extranet, open the Property tab, then Messaging preferences. In the Pulse app: More, then Messaging preferences.
  2. Message templatesOpen Message templates and create a new one: name, language and text. Insert the fields for the guest's name and dates so they fill in automatically.
  3. Schedule itChoose when the template is sent automatically, for example two days before arrival.
  4. Multiple languagesCreate a template with the same name for each language. Booking.com then sends the guest the version in their language.
  5. Automatic repliesIn the Automatic replies tab you can choose a template that answers a guest's message instantly.

Menu names can differ slightly depending on your Extranet language. If you use a channel manager (such as Rentlio), you can schedule messages there too, but make sure the same message doesn't go out twice.

Tips

1. Don't send codes right after booking

Put the door or key box code in the message two days before arrival, not in the booking confirmation. By then the booking is surely confirmed, and the code isn't floating around for weeks before the stay.

2. One link instead of a long text

A chat message gets lost among the others quickly. A guide link is there when the guest needs it, whether they are standing at the door or looking for the WiFi in the evening. If something changes, you update the guide, not every scheduled message.

3. Mind the send time

A message at 3 a.m. in the guest's time zone doesn't look professional. Send instructions in the morning, the reminder on the morning of arrival, and the check-out message in the early evening.

4. Check the message before switching it on

Look at the message preview and make sure the fields (name, date) filled in correctly. One wrong word goes to every guest.

Frequently asked questions

Are automated messages free?

Yes. Scheduled messages on Airbnb and templates with automatic sending on Booking.com are part of the platform and cost nothing.

Can I put a link in an Airbnb message?

After a confirmed booking, a link to your guide with instructions is common. Before confirmation Airbnb may hide contact details and links, so send the link in messages after the booking.

Which language should I write in?

On Booking.com, create a template with the same name for each language. On Airbnb it is safest to write in English or in both languages, like the messages above. The guide your link leads to opens in the guest's own language anyway.

What if a guest books at the last minute?

On Airbnb, turn on sending for last-minute bookings and short stays, otherwise a message whose time has passed is skipped. To be safe, also include the guide link in the booking confirmation.
